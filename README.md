The open-source, modular, code-first game engine for .NET.

OpenGE is an experimental game engine designed to provide a flexible and extensible foundation for game development. It aims to support a wide range of games, platforms, and development requirements through a consistent, modular architecture.

> [!WARNING]
> OpenGE is under active development and is not yet ready for production use. APIs, architecture, and project structure are subject to change.

## Overview

OpenGE is built around the idea that game development should be flexible without being unnecessarily complicated.

Rather than enforcing a single approach, OpenGE aims to provide a collection of composable systems that developers can use, extend, and integrate according to their needs.

The long-term goal is to support both 2D and 3D game development across multiple platforms while maintaining a unified development experience.

## Philosophy

OpenGE follows a few fundamental principles:

- **Code-first:** Game development is driven by code, without requiring a visual editor.
- **Modularity:** Systems are designed to remain independent, composable, and replaceable where appropriate.
- **Consistency:** APIs and abstractions follow predictable conventions throughout the engine.
- **Extensibility:** Developers can build upon existing functionality or introduce their own implementations.
- **Simplicity:** Common operations should remain straightforward without sacrificing flexibility.
- **Portability:** The architecture aims to accommodate different platforms and execution environments.

OpenGE favors explicit behavior, clear responsibilities, and practical abstractions over unnecessary complexity.

## Development

OpenGE is currently in an experimental stage.

Its architecture and public APIs are being actively developed and refined. Features may be incomplete, redesigned, or removed as the project evolves.

Development takes place primarily on the `develop` branch.

The project targets .NET and is developed using C#.
